# KabuSYS (株シス) - 日経225マイクロ先物 トレーディング＆バックテストシステム

KabuSYS は、日経225マイクロ先物等の市場データ（Excel / CSV）を元に、高精度なテクニカル分析、動的サポレジ検出、ハイ＆ロー・グリッドナンピン戦略のシミュレーション、およびパラメータ最適化を行う統合トレーディング＆バックテストシステムです。

Streamlit および Highcharts (Highstock) を採用したインタラクティブなWebUIを備え、ローソク足チャートの描画から売買シグナルの可視化、損益（エクイティ）推移の検証までを直感的に実行できます。

---

## 📌 主な機能と特徴

### 1. マルチタイムフレーム・データ管理
- **多様なフォーマット対応**: 日経225マイクロ先物の四本値データ（`.xlsx`, `.xls`, `.csv`）を高速パース。
- **タイムフレーム自動判別**: 1分足、3分足、5分足、10分足、15分足、20分足、30分足、60分足、日中日足、ナイト場足、終日日足などの各足種に柔軟に対応。
- **呼値・倍率対応**: 日経225マイクロ先物（呼値5円、倍率10倍）の証拠金や損益計算ルールを忠実に再現。

### 2. 高機能インタラクティブチャート (Highcharts / Highstock)
- **スムーズな描画**: 大量のローソク足データをズーム・パン（横スクロール）・クロスヘアカーソルで滑らかに表示。
- **指標オーバーレイ＆サブチャート**:
  - 移動平均線（SMA / EMA / WMA）、ボリンジャーバンド、一目均衡表、エンベロープ、HI-LOWバンド等
  - RSI、MACD、ストキャスティクス、ATR、DMI、乖離率等のオシレーター
- **売買シグナル・ポジション可視化**: バックテスト実行時の新規建て（ロング/ショート）、ナンピン買い/売り、利確/損切りポイントをチャート上に直接プロット。

### 3. 動的サポレジ（サポート・レジスタンス）解析エンジン
- **スイングハイ・ロー抽出**: 高値・安値のフラクタル構造から有意な価格帯（クラスター）を自動検出。
- **ロールリバーサル（サポレジ転換）**: ブレイクアウトしたレジスタンスがサポートへ、サポートがレジスタンスへと役割転換する動的ロジックを搭載。
- **リテスト・消滅判定**: 再テストされたラインの回帰回収や、現在価格周辺の有意ラインへの動的フィルタリング。

### 4. 高度なバックテストエンジン（High & Low グリッドナンピン戦略）
- **売買モード切替（IF検証機能）**:
  - **逆張りモード (CONTRARIAN)**: 直近N期間の高値突破でショート、安値更新でロング（平均回帰狙い）。
  - **順張りモード (TREND)**: 同一判定ポイントでブレイクアウト順張り（高値突破でロング、安値更新でショート）。
- **柔軟なロットテーブル設定**:
  - マーチンゲール、フィボナッチ、段階的ナンピン（例: `1, 1, 1, 2, 2, 2, 3, 3, 3, 4, 4, 4`）など自由な建玉配分が可能。
- **リスク管理機能**:
  - 設定金額での損切り（SL）、目標幅での利確（TP）、緊急時の同値撤退モード、必要証拠金チェック。
- **詳細なパフォーマンス評価**:
  - 純損益（Total P&L）、プロフィットファクター（PF）、勝率、最大ドローダウン（金額・%）、シャープレシオ、最大ナンピン段数分布など。

### 5. グリッドサーチ＆パラメータ最適化
- 複数タイムフレーム（5分足、15分足、60分足など）に対する2段階グリッドサーチ。
- ロバストネス（堅牢性）ヒートマップの自動生成。
- 年別・月別の損益推移レポート出力。

## 🚀 クイックスタート

### 1. 動作環境
- **OS**: Windows / macOS / Linux
- **Python**: 3.10 / 3.11 / 3.12 推奨

### 2. 依存ライブラリのインストール
必要な主要パッケージをインストールします：

```bash
pip install streamlit pandas numpy openpyxl matplotlib seaborn pytest
```

### 3. WebUI ダッシュボードの起動
以下のコマンドを実行すると、ローカルサーバーが起動しブラウザでダッシュボードが表示されます。

```bash
streamlit run src/frontend/app.py
```

ブラウザで `http://localhost:8501` にアクセスして操作します：
1. サイドバーから対象データファイル（例: `N225microf_2026.xlsx`）および足種を選択。
2. 表示したいテクニカル指標や動的サポレジをオン/オフ。
3. 戦略パラメータ（判定期間N、エントリー幅、グリッド幅、利確幅、ロットテーブルなど）を設定。
4. 「バックテスト実行」をクリックして、チャート上の売買履歴とKPIパフォーマンスを確認。

## 📊 システム仕様詳細

### 先物取引パラメータ (`src/backend/config.py`)
- **銘柄名**: Nikkei 225 Micro (日経225マイクロ先物)
- **呼値 (Tick Size)**: 5.0 円
- **取引倍率 (Multiplier)**: 10 倍 (1ポイント変動で10円の損益)

### ハイ＆ロー ナンピン戦略仕様 (`src/backend/grid_nanpin_strategy.py`)
- **判定基準**: 直近 `N` 本の高値 (`Highest High`) および安値 (`Lowest Low`)
- **エントリー条件**:
  - **逆張り (CONTRARIAN)**:
    - High + `EntryDelta` で新規売りエントリー
    - Low - `EntryDelta` で新規買いエントリー
  - **順張り (TREND)**:
    - High + `EntryDelta` で新規買いエントリー（上方ブレイク）
    - Low - `EntryDelta` で新規売りエントリー（下方ブレイク）
- **ナンピン挙動**:
  - ポジション保有中、前回約定価格から `GridStep` 円以上逆行した場合に追加ポジションを建て（ロットテーブルに従う）。
- **エグジット条件**:
  - **利確 (Take Profit)**: 全保有ポジションの加重平均建値から `TpDelta` 円順行した時点で全決済。
  - **損切り (Stop Loss)**: 含み損が `SlAmount` 円を超えた時点で強制全決済。
  - **同値撤退 (Emergency Breakeven)**: 有効時、特定条件下で建値付近での撤退を優先。
